# Analysis-of-single-tube-shell-and-tube-heat-exchanger
Analysed flow and heat conduction or variation in a single tube counter flow shell and tube heat exchanger using ANSYS FLUENT
# GEOMETRY 
1) Shell dia - 1m
2) shell inlet and outlet dia - 0.3m
3) tube dia - 0.3m
# MESHING 
1) element size = 0.2671 m (default)
2) nodes = 36456
3) elements = 95386
# solver 
1) K- epsilon(2-eq) , realisable with scalable wall function
# BOUNDARY CONDITIONS 
1) hot inlet = 90 degree C
2) cold inlet = 15 degree C
3) velocity - pressure model used ( inlet - outlet condition)
4) hot and cold fluid velocity - 1m/s
